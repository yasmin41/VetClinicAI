# n8n Workflows

This directory contains the n8n automation workflows for the VetClinicAI project.

## Workflows

1. **SQL Server Connection Test** — Retrieves veterinary clinic data from Microsoft SQL Server.
2. **Vaccination Reminder** — Identifies vaccinations due within seven days and prepares personalized reminder messages.

## Planned Features

- Telegram notification integration
- AI-powered veterinary assistant
- Automated daily scheduling

**Security:** Credentials, API keys, and passwords must not be committed to this repository.
